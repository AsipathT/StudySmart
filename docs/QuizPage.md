# AI Powered Quizzes — Page Documentation

**File:** `frontend/src/pages/QuizPage.jsx`
**CSS:** `frontend/src/pages/QuizPage.css`
**Route:** `/quizzes`
**Access:** Students only (admin is redirected via `StudentRoute`)

---

## Overview

The Quizzes page lets students take AI-generated multiple-choice quizzes tied to their study materials. Quizzes are automatically generated by the backend using the **Google Gemini AI** API by analysing the content of uploaded PDF materials. Students can also view their quiz history with scores and performance trends.

---

## Special Technology — Google Gemini AI

Quizzes are generated server-side using the **Google Gemini API** (`@google/generative-ai`).

- The backend receives a `fileUrl` pointing to an uploaded PDF material
- It extracts the PDF text using **pdf-parse**
- The extracted text is sent to Gemini with a prompt requesting multiple-choice questions
- Gemini returns structured JSON questions which are saved to MongoDB
- The frontend triggers this via a `POST /api/quizzes/generate` request

**Required API Key (backend `.env`):**
```env
GEMINI_API_KEY=your_google_gemini_api_key
```

> Get your API key from: https://aistudio.google.com/app/apikey

## Navigation Stages

The page uses a `stage` state to navigate between views:

| Stage | Description |
|-------|-------------|
| `list` | Grid of all subjects with quiz counts |
| `subject-quizzes` | Quizzes available for the selected subject + AI generate panel |
| `taking` | Active quiz interface with questions and options |
| `result` | Score screen after completing a quiz |
| `history` | Past quiz attempts with scores and dates |

## Features

### Subject List
- Displays all subjects as gradient tile cards
- Shows how many quizzes exist per subject
- Shows material count available for AI generation

### Quiz List & AI Generation
- Left panel: Lists existing quizzes with "Take Quiz" button
- Right panel: Lists all materials across units of the subject
- Each material has a **"Generate with AI"** button
- On click, the backend calls Gemini to generate questions from the PDF
- Newly generated quiz appears in the list immediately

### Taking a Quiz
- Questions displayed one at a time
- 4 multiple-choice options per question (A, B, C, D)
- Progress bar at the top showing completion
- Navigation: Previous / Next / Finish buttons
- Question progress dots at the bottom
- Answers are stored in `userAnswers` array indexed by question number

### Result Screen
- Displays score as a percentage (e.g. `80%`)
- Color-coded performance badge:

| Score | Label | Color |
|-------|-------|-------|
| ≥ 90% | Excellent | Green |
| ≥ 70% | Good | Blue |
| ≥ 50% | Average | Yellow |
| < 50% | Needs Improvement | Red |

- Option to view history or retake the quiz

### Quiz History
- Lists all past attempts for the current user
- Shows: quiz title, subject, score, date attempted
- Displays mini SVG progress ring per attempt
- Summary stats: total attempts, average score, best score

## API Endpoints

| Method | URL | Description |
|--------|-----|-------------|
| GET | `/api/subjects` | Fetch all subjects with units/materials |
| GET | `/api/quizzes/subject/:subjectId` | Get all quizzes for a subject |
| POST | `/api/quizzes/generate` | Generate AI quiz from a material PDF |
| POST | `/api/quizzes/attempt` | Submit a completed quiz attempt |
| GET | `/api/quizzes/history` | Get current user's quiz history |

### Generate Quiz Request Body
```json
{
  "subjectId": "<subject_id>",
  "materialName": "Introduction to Algorithms",
  "fileUrl": "/uploads/materials/intro-algo.pdf"
}
```

### Submit Attempt Request Body
```json
{
  "quizId": "<quiz_id>",
  "answers": [0, 2, 1, 3],
  "score": 8,
  "totalQuestions": 10
}
```

## AI Quiz Generation Flow

```
Student clicks "Generate with AI"
        │
        ▼
POST /api/quizzes/generate
        │
        ▼
Backend reads PDF → pdf-parse extracts text
        │
        ▼
Text sent to Google Gemini API with prompt:
"Generate 10 multiple-choice questions from this content..."
        │
        ▼
Gemini returns JSON questions array
        │
        ▼
Questions saved to MongoDB
        │
        ▼
Frontend receives new quiz and adds it to the list
```

## SVG Progress Ring (History)

Each quiz history tile includes a mini SVG ring showing the score visually:
- `strokeDasharray` = circumference of the circle
- `strokeDashoffset` = circumference × (1 - score/100)
- Color changes based on score tier (green / blue / yellow / red)
